
# 🇮🇳 Petroleum and Crude Oil Import & Export Dashboard – India (2023–24)

This interactive Excel dashboard presents a comprehensive analysis of **India's petroleum and crude oil import and export data for the financial year 2023–24**. Designed using PivotTables, slicers, and charts, this dashboard provides clear and insightful visualizations to explore trade trends and statistics in a user-friendly way.

---

## 📊 Features

- ✅ **Dynamic Slicers**: Filter data by product type, country, trade type (Import/Export), and time period.
- 📈 **Interactive Charts**: Auto-updating bar and pie charts to show key statistics.
- 🧾 **Pivot Table Summary**: Drill-down into trade volume and value by commodity and country.
- 🧠 **Clean & Structured Layout**: Easy-to-read visuals with logical flow and intuitive navigation.

## 📌 How to Use

1. **Download or Clone** the repository.
2. Open the `.xlsx` file in **Excel (preferably 365 or newer)**.
3. Use the slicers on the dashboard sheet to filter by:
   - Trade Type: Import / Export
   - Commodity: Crude Oil, Petroleum Products, etc.
   - Country: Exporting/Importing partner
   - Month or Quarter (if included)
4. The charts and tables will automatically update based on your selections.
